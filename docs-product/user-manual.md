## 快速开始

1. **登录**：浏览器打开租户管理后台地址（`https://<租户域名>`），使用管理员下发的账号登录；
   首次登录强制修改初始密码（NFR-SEC-04）。
2. **认界面**：左侧导航按角色呈现——销售（询盘工作台）、主管（看板与带教）、
   管理员（开通配置 / 知识库 / 成员）。
3. **5 分钟上手**：管理员完成[开通配置](#开通配置)后，销售在「询盘工作台」查看 AI 起草的
   回复，点击「采纳」或「修改后发送」；全部回复均引用知识库来源（FR-AG-008）。
4. **求帮助**：后台右上角「帮助中心」直达本文档站；FAQ 见[常见问题](#常见问题)。

## 开通配置

新企业接入全程**零代码**（FR-SAAS-002，四步向导，运营代操作或管理员自助）：

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① 企业信息 | 名称 / Logo / 主色 / 时区 / 语言 | 品牌即改即生效（白标，FR-SAAS-006） |
| ② 上传素材 | 拖拽上传产品手册 / 报价单 / FAQ | 支持 PDF/Word/Excel/图片，自动解析入知识库 |
| ③ 账号参数 | 录入平台账号与凭证 | 凭证提交即加密落库，仅掩码回显（NFR-SEC-04） |
| ④ 策略参数 | 模板预填 + 差异项确认 | 分级规则 / 风控上限 / 跟进节奏必须显式确认 |

提交后系统展示**资源预估**（知识块数 / 向量存储 / 预计耗时）；预估超套餐配额会先行
阻断并提示[升配额](#常见问题)。初始化进度可实时查看，失败文件支持一键重试。

### 品牌定制（白标）

管理员在「品牌设置」替换 Logo / 配色 / 产品名 / 登录页文案 / 自定义域名，
**无需任何构建发版**，刷新后台与培训端即呈现新品牌（UC-14）。自定义域名需完成
DNS TXT 归属验证与 CNAME 接入，验证通过后自动签发 HTTPS 证书。

### 成员与权限

「成员管理」按角色授权：租户管理员（全配置）、销售（工作台）、主管（带教与看板）。
全部敏感操作留审计（NFR-SEC-03）。

## 知识库管理

六库口径（产品 / 政策 / FAQ / 案例 / 邮件模板 / 通用）：

- **批量导入**：知识库 → 上传 → 选择库类型；解析失败清单可逐条重试；
- **清洗报告**：每次导入生成清洗报告（去重 / 乱码 / 截断统计）；
- **版本回滚**：发布出错可回滚到上一版本（FR-KB-024）；
- **检索验证**：检索试验台输入问题，验证 Top5 命中与来源引用（FR-KB-030）。

## 各业务模块

- **询盘工作台（销售）**：AI 草稿 → 人工接管发送；客户档案自动沉淀沟通记录；
- **培训带教（主管）**：话术演练、考试认证、新人带教路径（FR-TR 系列）；
- **看板与 ROI（主管）**：询盘量 / 回复率 / 45 秒达标率 / 介入率 / 成交额五口径；
- **独立站接待**：聊天组件嵌入后访客自动接待（FR-SITE-001），样式随租户品牌。

## 常见问题

- **Q：预估超配额被阻断？** A：联系平台运营升配额（FR-SAAS-003），或先精简素材；
- **Q：知识初始化失败？** A：进度页查看失败文件与原因，替换素材后点「重试」
  （仅补跑失败文件，已完成不重跑）；
- **Q：品牌修改后未生效？** A：刷新页面即可；若仍异常，检查接口返回（见
  [API 文档](api-guide.md)错误码章节）后联系运营；
- **Q：术语含义？** A：以需求规格说明书 §1.3 术语表为准（知识块 / 六库 / 清洗报告等）。
